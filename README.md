# Recovery Digital Twin — AI Personalized Recovery Plan

A responsive, front-end-only prototype inspired by the supplied concept images.

## What is included

- Hackathon domain selection screen (Track 06/10)
- Recovery Digital Twin overview
- AI recovery score and trajectory
- Personalized day-by-day recovery plan
- Live wearable/health monitoring
- 7-day AI recovery forecast
- Travel readiness / safe-to-fly decision support
- Doctor dashboard
- Interactive buttons, task completion, navigation, modal dialogs and toast notifications
- Supplied reference images in `assets/`

## Run the prototype

### Easiest
1. Extract the ZIP.
2. Open the folder.
3. Double-click `index.html`.
4. Click **OPEN PROTOTYPE**.

### VS Code
1. Open the extracted folder in VS Code.
2. Open `index.html`.
3. Right-click → **Open with Live Server** if you have the Live Server extension.
4. Or simply open `index.html` in Chrome/Edge.

No Node.js, database or installation is required.

## Important
This is a hackathon/UI prototype, not a medical device or clinical decision system. The health values shown are demonstration data.

## Main files

- `index.html` — complete UI structure
- `style.css` — responsive dark/neon visual design
- `app.js` — interactions and prototype logic
- `assets/reference_concept.jpg` — supplied concept reference
- `assets/reference_track.jpg` — supplied domain-selection reference

## Suggested hackathon flow

Landing → Open Prototype → Overview → Digital Twin → Recovery Plan → Live Monitoring → Travel Readiness → Doctor Dashboard.

For a production build, connect the UI to authenticated APIs, wearable/IoT streams, an ML model, clinician workflows, audit logs and validated medical/regulatory processes.
